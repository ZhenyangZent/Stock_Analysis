# 每週例行排程建議

建議每週六上午執行 `03_工具/weekly_refresh.py`。這個流程只更新公開資料、重新確認官方財報日期、計算台股法定期限事件窗並產生影子分類差異；**不建立正式快照**，正式快照仍需人工核准。

## Windows 工作排程器

1. 觸發條件設為每週六上午，例如 09:00（Asia/Taipei）。
2. 程式使用 Python 3.13 完整路徑，參數為 `-X utf8 03_工具/weekly_refresh.py`，起始目錄設為本專案根目錄。
3. 將 stdout、stderr 交由既有監控器收集；exit code 非 0 時通知使用者並附上最新 `04_回測/weekly_refresh/<RUN_ID>/report.json`。
4. 不要在同一時間安排其他會寫入價格、總經、事件或快照資料的工作。

## Claude 排程任務

排程提示詞應要求：在專案根目錄執行既有 `weekly_refresh.py`，保持失敗即停，不改規則或門檻，不自行建立正式快照；只有 exit code 非 0、需人工擷取清單非空或分類發生變化時通知使用者。狀態未變時保持安靜。

## 上線前檢查

先手動執行一次 `weekly_refresh.py --dry-run`，確認零寫入與分類差異可讀；再手動執行一次正式 weekly refresh 並檢查報告。排程本身需要另行授權，本文件沒有建立任何排程。
