# 文件／程式一致性對照表（T42）

本表只校正文義，不修改 `rules.json`、分類門檻或數值規則。正式輸出以目前 schema 2 影子分類與 canonical gate 為準；舊 schema 1 路徑保留相容性，但不得誤寫成現行四分類。

| 項目 | 文件寫法 | 程式實際 | 處理 |
|---|---|---|---|
| 正式分類集合 | 可列入研究／等待／無法判定／資料不足 | `verdict.py` 的 schema 1 相容路徑仍可能輸出 `待查證`、`觀望：事件前` | 兩者標為內部／舊路徑 gate 狀態；對外正式四分類不得新增第五、六類 |
| C5 無揭露 | C5 為「有／無」 | `ai_fields.grade_c5()` 只有在必查清單完整時，才可用 `X_ZERO_NO_DISCLOSURE` 表達 X=0 | 明定為「已查證無揭露」；缺文件、缺章節或缺抽取一律是 null，不得當 0 |
| I4 彙總 | 四大雲端業者資本支出 | `i4_capex.current_snapshot()` 先判每一家方向，再依上修／下修家數形成廣度 | 文件改稱家數廣度，不再描述成四家公司金額加總 |
| I2／I2Q | 年度財測與下一季財測 | rules 1.12.0 起，`aggregate_i2_combined()` 每家公司優先 I2，缺合格 I2 才用 I2Q，同公司只計一次 | I2Q 是 I2 的補位來源，不是第二個正式計分指標 |
| 雙抽取合併 | 兩份獨立抽取 | 任一為 null 則結果為 null；C5 不一致取較保守的「有」；C6 不一致取較低等級；I2／I4 不一致依保守方向與證據規則處理 | 文件明列「null 不回退、分歧採保守」；不得把一致性失敗包裝成精確值 |
| MU 估值 | 循環股使用 PB | 規則指定 MU 用 PB，但 `valuation_v1.py` 目前回報 `NOT_IMPLEMENTED_TRAILING_PB` | 文件不得宣稱 MU 已有可用 PB；維持資料不足／未實作限制 |
| AI 欄位現行性 | 使用最近已驗證值 | 1.12.1 正式路徑可能在最新列為 null／失效時回退舊列；T42 的 1.12.2 候選改為「每欄只看最新列，不現行即 null」 | 候選只產差異，不啟用；待 Claude 複查與獨立升版 authority |
| 評估起點 | 以正式快照為樣本 | 舊評估從 `anchor_session` 收盤起算，且同組重複列可多次計入 | T42 評估程式改為發布後下一個共同交易日收盤起算，並按公司／anchor／rules_version 取最早發布一次 |

## 文字邊界

- `待查證`、`觀望：事件前` 是相容性或 gate 狀態，不是外部介紹中的新增正式分類。
- `X_ZERO_NO_DISCLOSURE` 的「0」是完整檢查後的證據結論，不是缺資料的預設值。
- 本表不授權啟用 rules 1.12.2，也不授權建立正式快照。
