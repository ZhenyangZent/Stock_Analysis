# 共用資料

- `AI產業鏈研究資料庫_2026-10-05.xlsx`：公司、季報、月營收、事件、證據總帳。只新增列，不改寫既有列。
- `prices.csv`：未還原收盤價，欄位 `date,ticker,close,volume,source,fetched_at`。由 `python 03_工具/fetch_prices.py` 寫入，只新增。
  來源與抓取時間記在每一列，不另外寫來源檔。
- `corporate_actions.csv`：配息與分割，欄位 `date,ticker,type,value,source,fetched_at`。
  `type` 只有「現金股利」（value 是每股金額）與「分割」（value 是每 1 舊股換成幾股）。`date` 是除息日或分割生效日。
  美股由抓價程式自動寫入；**台股要人工補**，來源請填公開資訊觀測站或交易所的網址。
- `prices_差異.csv`：重抓時發現和既有資料不同的數字。既有資料不會被改寫，請人工判斷哪個對。

- `macro.csv`：市場環境用的公開總經數列（利率、殖利率、油價、失業率、物價、信用利差），欄位 `date,series_id,value,source,fetched_at`。由 `python 03_工具/fetch_macro.py` 寫入，只新增；來源是 FRED 的公開下載，不需要金鑰。修訂過的數字記在 `macro_差異.csv`。

## 更新股價

在自己的電腦上執行（需要網路）：

```
python 03_工具/lock.py acquire <名稱> "更新股價"
python 03_工具/fetch_prices.py
python 03_工具/lock.py release <名稱>
```

- 台股不需要金鑰。每檔每個月一次請求，第一次抓全部大約 10 分鐘，之後只抓新的月份。
- 美股需要 Tiingo 的免費金鑰。程式依序從三個地方找：環境變數 `TIINGO_API_KEY`、環境變數 `AI_STOCK_ENV_FILE` 指向的檔案、家目錄的 `.ai_stock/.env`（內容一行 `TIINGO_API_KEY=金鑰`）。
  **金鑰不可放在這個資料夾裡**，放了程式也不會讀，只會提醒你搬走。
- `python 03_工具/fetch_prices.py --check` 可以不連網檢查有沒有缺交易日（拿同市場其他代號有交易的日期來比）。
  沒有金鑰時會跳過美股，可以改用 `--import-csv 檔案.csv --ticker MU` 匯入自己匯出的 CSV。
