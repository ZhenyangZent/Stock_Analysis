# 股票判斷

這個資料夾是一套「AI 幫忙查資料、固定規則下判斷、事後可以回測」的系統。
多個 AI（Claude、GPT、Gemini、Codex）會在這裡一起工作，所以**每個資料夾有明確的用途和寫入規則**。

不是投資建議。輸出的「可列入研究／等待／不行」是研究分類，最後的買賣由使用者自己決定。

## 資料夾分類

| `02_執行紀錄/` | 每次判斷產生的 JSON，一次一檔 | 只新增，**永不修改**（回測靠它） |

## 1.3.3 最小資料脊椎與財務體質影子模組

- 發行人與證券分開識別；`TSM` 與 `2330` 同發行人但不同證券、幣別與價格序列。
- schema 2 只保存事件 ID 與原始時間；驗證及判斷都從 canonical 事件表與日曆重算事件距離，不信任紀錄內宣告的衍生值。schema 1 的舊距離不回寫。
- 新 observation 保存來源公布、可得與抓取時間，回補資料不冒充當時可得資料。
- `portfolio.json` 不存在代表 `NOT_PROVIDED`，工具只讀、不會替使用者建立。
- V1 由程式依 `run_cutoff_at` 從 canonical observations 重算；沒有完整 60 個月 point-in-time 倍數資料時回傳資料不足，不接受紀錄自行填值。
- schema 2 的個別持股上限換算尚未實作，輸出會明列 `NOT_IMPLEMENTED_SCHEMA2`，不會暗示已做部位檢查。
- 1.2.1 已通過 Claude 唯讀複查；schema 2 的正式資料仍須依各資料模組的獨立啟用狀態匯入。
- `health.py` 依發行人計算 H1–H7 財務體質燈號，整合進風險報告，但維持 `SHADOW`，不影響研究分類。
- 9 家美股的 SEC 申報數字已寫入 canonical observations；SEC 公司只接受 `financial_tag_map.json` 的精確白名單。折舊與無形資產攤銷只有同期間兩者齊全才可相加。
- 「已查證為零」要記錄申報文件、查證者、日期與唯一適用期，且另一個 AI 核准後才可寫入 canonical。待複查聲明只能做不寫帳本的試算。台股與 TSM 仍需 MOPS XBRL adapter。
- `health.py` 的輸出包含每家公司 H1–H7 的數值、實際期間與觸發原因；比率期間必須對齊，135 天由各指標自行檢查。
- 1.3.2 的 35 筆負債更正、過期警示保留規則與兩筆 ANET 零值聲明已通過 Codex 唯讀複查；門檻未變。
- H7 在最新年度申報晚於最新單季時，改用完整年度對完整年度，絕不把全年股數和單季股數混比。ANET 年報使用的等義資本支出標籤已納入明示 fallback。
- MRVL 的短期投資零值仍為 `PENDING_INDEPENDENT_REVIEW`，只能試算；AVGO、ETN、COHR、GEV 與台股／TSM 的未解欄位仍保持資料不足，不以近似項目或缺標籤推定。

## 每次判斷的流程（一句話版）

AI 只負責**查資料並填表**，產生一個執行紀錄 JSON；判斷結果由 `03_工具/verdict.py` 依 `rules.json` 計算。
同一份輸入，不管是哪個模型填的，算出來的結果一定相同。

## 1.6.1 營收趨勢資料

- 九家美股公司的單季營收與毛利由 SEC Company Facts 精確白名單匯入；不做模糊標籤配對。
- 沒有直接毛利標籤的公司，只有同期間營收與成本都存在時才以相減產生毛利，來源 components 與推導方式一併保存。
- `trend.py` 維持影子模式。趨勢帳本含資料指紋與 append-only 更正鏈，不影響 `verdict.py`。
